                             # MySQL Assignment 1 – DDL Commands & Constraints

## **Topics Covered**

- Database Creation – Creating and selecting databases using CREATE DATABASE and USE.
- Table Creation – Creating tables using CREATE TABLE.
- Table Modification – Adding, modifying, dropping, and renaming columns using ALTER TABLE.
- Table Renaming – Renaming existing tables using RENAME TABLE.
- Table Truncation – Removing all records using TRUNCATE TABLE.
- Database & Table Deletion – Removing tables and databases using DROP.

## **Constraints Used**

- PRIMARY KEY – Uniquely identifies each record.
- NOT NULL – Prevents empty values.
- UNIQUE – Prevents duplicate values.
- AUTO_INCREMENT – Automatically generates sequential IDs.
- ENUM – Restricts values to predefined options.
- CHECK – Validates values based on a condition.
- DEFAULT – Assigns a default value when none is provided.
- FOREIGN KEY – Establishes relationships between tables.
